# Приложение анализа транзакций

## Описание:

Приложение для анализа транзакций, которые находятся в Excel-файле.
Приложение будет генерировать JSON-данные для веб-страниц, формировать Excel-отчеты,
а также предоставлять другие сервисы.

## Примеры использования функций:

+ Модуль utils
содержит вспомогательные функции, необходимые для работы функции страницы «Главная»:

**load_user_settings() -> Dict[str, List[str]]**
    
Загружает пользовательские настройки из файла user_settings.json и возвращает 
словарь с настройками пользователя

**get_greeting(current_datetime: datetime) -> str**

Возвращает приветствие в зависимости от времени суток

**calculate_card_operations(df: pd.DataFrame) -> List[Dict[str, Any]]**

Рассчитывает операции по картам: общая сумма расходов и кешбэк.

**get_top_transactions(df: pd.DataFrame, top_n: int = 5) -> List[Dict[str, Any]]**

Возвращает топ-N транзакций по сумме платежа.

**get_currency_rates(currencies: List[str]) -> List[Dict[str, Any]]**
    
Получает текущие курсы валют через API.
Использует API Центрального банка РФ.

**get_stock_prices(stocks: List[str]) -> List[Dict[str, Any]]**
    
Получает текущие цены акций через API.
Использует Alpha Vantage API (требуется API ключ).

    
+ Модуль views
содержит функцию для страницы «Главная»:

**main_page(date_time_str: str) -> Dict[str, Any]**
    
Главная функция для страницы "Главная".
Принимает строку с датой и временем в формате 'YYYY-MM-DD HH:MM:SS'
Возвращает JSON-ответ с данными для главной страницы

+ Модуль services
содержит функции сервиса «Простой поиск :

**load_transactions_from_excel(file_path: str) -> List[Dict[str, Any]]**

Загрузка транзакций из Excel-файла.

**search_by_phone_numbers(transactions: List[Dict[str, Any]]) -> str**
    
Поиск транзакций, содержащих в описании мобильные номера.
Принимает список словарей с транзакциями.
Возвращает JSON-строку с транзакциями, содержащими номера телефонов.
    

+ Модуль reports
содержит функции сервиса «Траты по категории»:

**report_to_file(filename: Optional[str] = None)**

Декоратор для сохранения результатов отчетов в файл.
Принимает имя файла для сохранения отчета.
Если не указано, генерируется автоматически.
    
**spending_by_category(transactions: pd.DataFrame, category: str, date: Optional[str] = None) -> str**
    
Отчет о тратах по заданной категории за последние 3 месяца.

 

+ Модуль main
Запуск всего функционала
 считывания финансовых операций из Excel.
